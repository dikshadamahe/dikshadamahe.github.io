# Diksha Damahe — Portfolio

An interactive Indian monsoon world portfolio. Explore my projects, work, and publications by travelling through a rainy landscape.

**Live:** https://dikshadamahe.github.io/

## Tech Stack

- Next.js 16 (App Router, static export)
- React Three Fiber + Drei (3D scene)
- GSAP (animations)
- Zustand (state management)
- Tailwind CSS
- Howler.js (ambient audio)

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000
